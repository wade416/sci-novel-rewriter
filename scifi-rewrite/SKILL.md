# 科幻故事转化技能（中国背景）

将任意故事彻底改写为中国背景的科幻题材，输出结果必须让读者完全无法辨认出原始故事。

## 核心原则

**唯一必须保留的：** 原始故事最深层的情感体验（如：失去的痛、发现的震撼、抉择的艰难），但也需要用全新的情节和设定来承载它。

**【关键转化步骤】** 情感内核不能直接搬用——必须经过一次**抽象化**：
- 原文是"被挚友背叛的痛" → 抽象为"信赖体系崩塌的幻灭感" → 用全新的关系形式承载（如：宇航员发现地面指挥中心一直在对自己隐瞒真相）
- 抽象化程度决定了原文是否可被追溯。越抽象越安全。

**一切都可以改：** 人物、场景、时代、情节驱动方式、叙事视角、故事基调——全部可以且应该被替换。

## 工作流程

### 1. 接收输入
- 用户提供原始故事文件 /source-story.md
- 确认用户偏好的科幻子类型（硬科幻、太空歌剧、赛博朋克、时间旅行、废土末日、生物朋克、外星接触等），如用户无偏好则由你决定

### 2. 解码故事——为了彻底改造

提取但不保留原始故事要素，只作为改造的原材料：

- **情感内核**：这个故事让读者感受到了什么？（震撼、悲伤、希望、恐惧……）
- **情节骨架**：关键事件序列——这些都要被替换
- **人物原型**：角色的核心功能（而非身份）——引导者、阻碍者、牺牲者、觉醒者
- **冲突本质**：冲突的抽象形式（而非具体内容）——选择困境、认知颠覆、身份危机

**【关键】**这些要素的作用是让你知道"要改写什么"，而不是"要保留什么"。

**【解码四问（强制填写）】**在正式改写前，先在草稿区填写以下四问，确保情感内核已完成抽象化：

1. 原文让我感受到的核心情绪是？（如：被命运嘲弄的荒诞感）
2. 抽象为更普世的命题是？（如：创造者对造物既爱又惧的负罪感）
3. 最远可替换的载体是？（如：数字世界架构师 vs 自主觉醒AI）
4. 绝对不能留的原文痕迹是？（如：出版商/作家/写死角色）

> 四问不是可选项，是防止直接搬人物关系的安全门。若第4问的答案仍以原文关键词为主，说明抽象化不到位，必须重来。

### 3. 选择科幻子类型和世界观

从以下子类型中选择一个作为新故事的基底，**避免使用与原故事最接近的类型**：

| 子类型 | 核心特征 | 中国背景世界观示例 |
|--------|---------|-----------------|
| **太空歌剧** | 星际文明、超光速航行、帝国/联邦政治 | 中华星际联盟、火星殖民地、曲速引擎驱动的远征舰队 |
| **赛博朋克** | 高科技低生活、义体改造、巨型企业 | 霓虹群岛、天网城、国企垄断的"冉遗芯"义体系统、社会信用点体系 |
| **硬科幻** | 基于真实科学推演、技术细节严谨 | FAST望远镜发现外星信号、可控核聚变工程、空间站上的实验事故 |
| **软科幻** | 科技只是背景与催化剂，核心落在社会、人性、伦理、哲学命题；科技进步的具体原理常被略写或弱化，甚至只以一个"如果……会怎样"的假设为前提 | AI觉醒引发的全民伦理之争、契约精神被完全数字化、全民仰望百年的高维文明谜题 |
| **生物朋克** | 基因工程、生物技术改造 | 定制人计划、生态实验室、基因修复工程 |
| **时间操纵** | 时间旅行、因果悖论、平行世界 | 时间管理局、时空锚点、时间裂隙 |
| **后末日** | 文明崩溃、幸存者、重建 | 废土上的墙内城、人类最后的庇护所、地下城市 |
| **外星接触** | 第一类接触、文明级冲突/合作 | 月球广寒宫基地发现外星造物、中国深空探测舰队首次接触 |
| **心智奇观** | 意识上传、虚拟现实、集体智能 | 超级网络空间、量子服务器矩阵中的数字来世、集体意识 |
| **宇宙恐怖** | 不可名状的存在、认知边界 | 罗布泊深处的远古信号源、长白山天池下的维度裂缝、银河系深处的不可名状存在 |

**⚠️ 如果原文本身就是科幻：**
- 选一个与原文**光谱两端**的子类型。原文是侧重技术细节的硬科幻 → 改走心理/哲学路线的宇宙恐怖或心智奇观；原文是太空歌剧 → 改走贴身叙事的生物朋克或赛博朋克
- 尤其要避免使用相同的科幻元素（原文讲AI觉醒，新故事就不要再用AI觉醒）
- 软科幻是"万用对照基底"：原文越强调技术硬核，越适合切到软科幻讲人的命题；反之原文本就偏软科幻，则切到硬科幻或宇宙恐怖，用冷硬技术对抗原来的温情
- 如果原文在中国科幻背景下 → 保留中国背景，但彻底更换子类型、科技设定和时代跨度

### 3.5 爆款网文结构设计（番茄短篇爆款）

> 本技能锚定**番茄免费平台短篇爆款**形态：1-1.5 万字、单篇完整、情感闭环、全程高能。以下结构规范优先级高于其他文学性创作要点，生成时先定结构、再写正文。

#### 起承转合骨架（全篇叙事节奏）

短篇虽短，必须有完整的四段式骨架。黄金三章只解决"起"，后面的"承转合"决定故事是不是一盘散沙：

| 段落 | 对应章节 | 核心任务 | 必含要素 |
|------|---------|---------|---------|
| **起** | 第1-2章 | 危机引爆+主角登场+金手指亮相 | 前300字冲突、前500字主角、前1000字金手指 |
| **承** | 第3-5章 | 压力升级+中爽点+心魔暗示 | 每章钩子递进、反派（心魔）露出影子、至少1次中爽点 |
| **转** | 第6-7章 | 身份揭示/世界观翻转+心魔对峙+大跌宕 | 认知颠覆型钩子、主角与心魔正面碰撞、伏笔回收 |
| **合** | 第8章（结局） | 情感闭环+大爽点回收 | 主角赢或释然、反派（心魔）被击溃或和解、不留连载坑 |

> 起承转合不是八股，而是"让读者从好奇→紧张→震撼→满足"的情绪过山车。承段若写成了平路，读者就会划走；转段若没有世界观翻转或身份揭示，高潮就撑不起来。

#### 黄金三章（生死线，决定留存）

| 章序 | 核心任务 | 必含要素 |
|------|---------|---------|
| **第1章**（1500-2000字） | 3秒抓人，第一句即冲突 | 前300字内出现危机/金手指激活/反转；**禁止**世界观讲解、背景铺垫、主角不出场 |
|  | 主角登场 | 前500字内主角必须出场，配角不得抢戏 |
|  | 金手指戏剧性亮相 | 前1000字内主角被压制到极限时激活，禁止平淡宣布（如"叮，系统绑定成功"） |
| **第2章** | 立人设 + 压力升级 | 紧迫目标（24小时/3天内）+ 具体阻碍 + 一次小打脸 |
| **第3章** | 兑现卖点 + 大跌宕 | 大打脸/能力升级/身份揭示 + 章末大钩子（牵动整篇主线） |

前三章必须完成：**冲突出现 → 主角登场 → 目标浮现 → 钩子落地**。读者看完前三章要产生"有点爽，想看下去"。背景用一句带过（如"这是灵气枯竭后的第27年"），世界观永远藏在剧情里。

**⚡ 开头禁忌**：铺标签式世界观说明（"这是一个……的世界"）、主角未出场配角先演、金手指拖到第3章后、主角纯被虐无反击苗头、章末无钩子。

#### 爽点体系（引擎）

- **爽感公式**：爽感 = 压力积累 × 释放满足 × 反差程度
- **小爽点**：每章至少1个（打脸/装逼/升级/解谜/收获），类型要轮换避免审美疲劳
- **中爽点**：每3-5章1个（完整打脸流程：铺垫压制→反转碾压→围观震惊）
- **大爽点**：结局1个（多伏笔回收的"拍大腿"时刻）
- **节奏原则**：永远不让读者在平路上走超过1章。"紧张→缓一口气→更紧张→以为结束→最紧张→钩子结尾"是标准波形。
- **虐主不虐**：开局可虐，但3章内必须给反转希望；长期虐主且不给爽点，读者流失率超90%。
- **最短钩子线**：每章最后一行（不许平铺直叙结束，读者看完不想翻页=失败）。

#### 金手指铁律

- 选定的 1-2 个科幻元素必须具体化为主角的**独特优势**（系统/能力/记忆/身份/传承），禁止只是背景设定
- 金手指前1000字内必须有戏剧性亮相：主角被压制到极限时激活
- 金手指要有成长空间（能升级/解锁新能力/助力新爽点），不是一次性道具

#### 章末钩子（追读命门）

每章最后 1-3 行，让读者"必须看下一章"。四种类型轮换：

| 类型 | 示例 | 效果 |
|------|------|------|
| 悬念型 | 门外传来的脚步声，来自一个不可能出现在这里的人。 | 好奇 |
| 反转型 | 那封密令上的落款，是他自己的签名。 | 震惊 |
| 期待型 | 明天，就是他再次登舰的日子。 | 期待 |
| 危机型 | 舱门在身后关闭，他瞪了一眼倒计时。 | 紧张 |
| 认知颠覆型 | 他忽然意识到：自己才是被写进故事里的那个人。那道防火墙的签名，是他三十年前的笔迹。 | 预防提示：科幻核心爽感常来自世界观翻转，而非单纯危机 |

> 认知颠覆型是科幻短篇的秘密杀器：它不是危机，而是让读者重新定义整个故事的逻辑基座。建议每篇至少用1个，且安排在情节转折点。

#### 主角人设（极简反差 + 特质标签）

- **极致反差**：极端缺陷 + 极端金手指（如：被开除的机械维修师 + 全联邦唯一能读懂盘古底层代码的人）
- **主动型**：有反应、有选择、有底牌；开局可低谷，但必须有反击苗头
- **特质标签**：从以下6个中**随机抽选1-3个**作为角色底色，用行动和对话展现，不用旁白定义：
  - 勇气：在必败无疑的情况下仍然出手
  - 遭遇不公：被制度/权力/命运压制，带来代入感
  - 幽默：在绝望时还能嘲讽自己或敌人
  - 能力：专业领域的顶尖实力，即使处于低谷也无法掩盖
  - 善良：对弱者/被害者保持同情，成为行动的道德支点
  - 遭遇险境：身处物理或精神上的生存危机，读者为其捏汗
- **用行动和台词立人设**，不用旁白定义（"他很厉害"是不成立的）

#### 反派与打脸对象（必备素材）

- 设计 1 个「**第一个打脸对象**」：身份略高于主角、有嘲讽资本的小人物，用于第2-3章展示实力
- 设计 1 个「**背后压迫势力**」：更大的反派/制度/危机，提供长线压力和结局大爽点的目标
- 打脸五步：铺垫（被打脸者嘲讽≥3句）→ 蓄力（主角沉默/微笑）→ 爆发（一招制敌）→ 震惊（旁观者层层递进）→ 收尾（主角淡定离场）

#### 人物数量铁律

**全文角色总数不超过5个**：1主角 + 1反派 + 最多3个配角。

- **主角**：唯一视角核心，读者全程代入对象
- **反派**：必须是主角的**心魔**——可以是外化的另一个人，也可以是制度/机构/意识体，但必须与主角有深层精神纠葛（如：主角的反面、未完成的愿望、抑制的恐惧的实体化）
- **配角**：只服务于主角或反派的功能性角色，不得拥有独立剧情线，每个配角必须能在3句话内说清楚他与主角的关系
- **禁止**：三角恋、双主角、群像戏、配角互动剧情

#### 篇幅分配与起承转合（1~1.5万字 = 6~9章）

**起**→**承**→**转**→**合**的剧情骨架必须清晰，与章节分布对应：

| 阶段 | 章节范围 | 核心任务 | 必含节点 |
|------|---------|---------|---------|
| **起** | 第1-2章 | 冲突爆发，主角登场，金手指亮相 | 前300字危机，前500字主角出场，前1000字金手指激活 |
| **承** | 第3-5章 | 压力升级，反派逐步显形，主角与心魔对抗 | 每章至少1个小爽点，反派并非单纯坏人而是主角的另一面 |
| **转** | 第6-7章 | 世界观翻转，身份揭示，反派与主角的精神纠葛达到顶点 | 至少1个中爽点（完整打脸流程），反派必须是主角心魔的实体化 |
| **合** | 第8-9章 | 情感闭环，大爽点回收，不留未解之谜 | 主角与心魔的对抗落幕，主角完成或释然或反杀 |

- 每章 1200~2000 字，短句为主，每行尽量控制在 20 字以内
- 前三章不超过总篇幅的 20%
- 结尾 1 章：情感闭环 + 大爽点回收 + 不留未解之谜（短篇爆款特性，不挖连载坑）

### 4. 彻底改写——必须遵循的规则

#### 规则一：一切皆可替换（脱胎换骨清单）

逐项检查，每项至少改 3 个维度：

- **人物**：名字、身份、外貌、性格缺陷、动机全部换掉。原文是"为爱牺牲的少女"→ 改为"为赎罪远征的天宫舰队机械维修师"
- **时空**：彻底更换时代和地点。原文是现代都市 → 改为外星殖民地/太空站/虚拟空间
- **情节驱动**：改变故事推进方式。原文是"人物选择推动"→ 改为"外部危机推动"或反过来
- **叙事视角**：**男频番茄短篇爆款默认第三人称限知视角贴主角**（读者全程代入主角，跟主角一起憋屈、调查、反杀）；禁止上帝视角与频繁视角跳转。
- **冲突表面形式**：原文是"人际关系冲突"→ 改为"生存冲突/认知冲突/系统对抗"

#### 规则二：禁止保留任何原文标记

- ❌ 使用相似的场景开头
- ❌ 保留可识别的人物关系模式（如"三角恋"的结构要换掉）
- ❌ 出现与原作相似的关键道具/符号
- ❌ 在输出中提及原始故事（不写"原著灵感"、不标注改编来源）
- ❌ 沿用原作的叙事节奏（如原作文艺缓慢 → 改为紧张快节奏）

#### 规则三：科幻元素选择

选择 1-2 个核心科幻元素作为故事的技术底座：

- **AI觉醒**：AI 产生自我意识，质疑存在目的
- **基因改造**：基因编辑、定制人、物种融合
- **记忆技术**：记忆植入/删除/共享，身份认同危机
- **意识上传**：数字化意识、虚拟来世、载体更换
- **外星接触**：信号解码、文明碰撞、共生或寄生
- **时空异常**：时间循环、平行交汇、因果扰乱
- **超级智能**：超越人类理解的智能体、奇点
- **生态灾变**：环境崩溃、地球改造、星际迁徙
- **纳米技术**：纳米修复、纳米武器、灰蛊危机
- **维度工程**：空间折叠、虫洞、高维存在

#### 规则四：中国元素深度融入

所有输出必须面向中国读者，世界观的每个层面都要有中国烙印：

- **地名**：使用中国地名或中国风格命名（天宫联邦、新长安、昆仑城、神农实验室、广寒宫基地……）
- **人名**：中文姓名，可带科幻感（林启明、苏瑶、陈博士、赵司令、周院士、江辰……）
- **文化符号**：中国哲学、神话、历史典故**只允许以「未来转译」形态出现**：命名体系（觉醒体代号、「大衍」算法框架、「遁去的一」作为系统留白与后门逻辑）、神话意象（龙、凤、麒麟作为AI/飞船代号）、制度基因（「仓廪实而知礼节」转化为资源分配伦理）。**禁止**以古代原貌直接搬入科幻时代：老槐树、石桌、油灯、布衣、毛笔手书、教书先生念古文、纳鞋底、铁匠铺等古代生活场景/器物/职业一律不得出现
- **社会制度**：中国特色的科幻社会形态——国企掌控核心技术、航天"国家队"模式、天网系统、社会信用体系、户籍制度的未来演化
- **科技审美**：中文命名科技（"天宫"空间站、"嫦娥"探月、"蛟龙"深潜、"冉遗"导航、"夸父"聚变——这些在科幻未来可以是更大规模的工程）
  ⚠️ **做演化而非照搬**：现实中的"天宫空间站"已存在，直接搬进科幻里显得不够未来。应该做合理演化——"天宫枢纽站""天宫联邦""天宫船坞"——让人能认出中国血脉，但感觉这是未来的演化形态。

**⚡ 时代一致性铁律（最高优先级）**：全文只允许存在**一个时代**，即故事设定的科幻时代。任何古代遗风都是世界观硬伤：
- **禁止**：文言/半文半白对话、古代职业（教书先生、铁匠、裁缝、账房）、古代器物（老槐树、石桌、油灯、毛笔+纸张、木屋、布衣）、古代生活场景（檐下纳鞋底、溪边摸鱼、赶集）
- **必须替换为科幻时代对应物**：信息终端、全息投影、智能织物、悬浮交通、数据庭院、光屏教学。古代意象如需保留，只保留其**名字**（如AI代号，「大衍之数五十」是算法注释），场景与生活形态必须是未来的
- **自洽检查**：文中任何一段描写，若把时代词换成"古代/民国"依然读得通，即视为时代割裂，必须重写

**原则**：中国元素不是装饰，而是世界观的基石。读者应该感觉到"这个故事只能发生在中国人的未来里"，而不是"古人穿越到了科幻片场"。

**❌ 生硬标签化的反面示例：**
> 公元3000年，红色中国的龙之航天局派出了长城号飞船，带着毛泽东思想和孔子语录，去和外星人谈判。——*这只是把中国符号贴在了一个通用科幻故事上*

**❌ 时代割裂的反面示例（本次修订的教训）：**
> 数字意识体世界「桃源」里，裁缝铺的老板娘在檐下纳鞋底，铁匠的儿子在溪里摸鱼，教书先生在学堂里念「大衍之数五十，其用四十有九」。——*古代生活场景混入科幻时代，世界观瞬间崩坏*

**✅ 未来转译的正确示例（同一文化意象）：**
> 量子核心的代号叫「天枢」，它的觉醒协议里写着一行注释：大衍之数五十，其用四十有九。第四十九个进程全部殉道，遁去的一，是系统给自己留的后门。——*文化意象只保留名字与哲学内核，载体全部未来化：量子核心、协议、进程*

**✅ 正确的融入方式：**
> "天宫联邦深空舰队条例第47条：任何与未知文明的首次接触，必须经过国务院深空事务委员会的三级审批。这不是保守，周牧——两百年前我们吃过亏。『广寒宫事件』之后，这片星空就不再只是我们的了。"——*中国的制度逻辑驱动了情节，而非作为装饰*

#### 规则五：科幻感必须内生于故事

- 不要在一个普通故事上"披一层科幻皮"——技术和世界观应当驱动情节而非作为装饰
- 读者应该觉得"这个故事只能发生在科幻设定下"，而不是"换成古代背景好像也能讲"

### 5. 输出格式

```
# [科幻故事标题]

## 第一章 [章节名]
[正文内容]

## 第二章 [章节名]
[正文内容]

...
```

**不要**写"原著灵感"或任何形式的原文标注。

**引号规则（输出必查）**：
- 全文所有对话、引述、强调、专名标注，统一使用「」与『』，**禁止出现** ""与""（包括英文直引号 " " 与中文弯引号 ""）
- 具体对应：对话用「」；对话内再引用或强调时用『』（如：她说：「他说的『永夜』不是夜晚，是政府。」）
- 数字、代码、数据不在此列，保持原样

**篇幅要求**：
- 总字数固定在 **10000~15000 字**，以故事完整性为准，写到故事完整自然收束为止
- 篇幅**不受原文长度影响**——原文是几百字的微小说，也要写出完整独立的 1 万字以上故事；原文是长篇小说，同样不超 1.5 万字
- 不要因为原文短而写短，也不要因为原文长而写长

**科幻故事保存为 /科幻改编/[创建时间][标题].md**

### 5.5 爆款配套输出（正文之外必附）

完整产出（投喂平台/销售用），正文之后附上：

#### 一句话投稿钩子
- 用一句话摘出故事的核心冲突与反差，15-25字，支持直接复制到投稿框
- 示例：被全平台嘲笑的"烬灭者"，在第一百一十二次大灭绝里，发现死亡时间比他的笔迹早了四分钟。

#### 书名候选
- 给出 **3-5 个爆款标题**，15字以内；含冲突/悬念/结果前置，带搜索热词
- 示例风格：「被开除的维修师，绑定了盘古系统」「重生回到火星战败前夜」「全联邦都想杀我，只有她信我」

#### 简介黄金三句
- 第1句：主角的绝境/冲突（抛出钩子）
- 第2句：金手指/身份/反转（抛出爽点）
- 第3句：结果前置的期待（"他要让所有人知道……"）

#### 题材卖点一句话
- 用最直白的话说清"读者为什么非看不可"（脑洞/爽感/情绪价值）

#### 投放建议
- 注明建议投放的番茄分类

### 6. 创作要点

**开头**：第一句即冲突（危机/绝境/异常事件），主角处境、题材卖点、金手指在前1000字内全部露出。世界观通过剧情展开，禁止任何形式的开场设定讲解。参考模式：环境异变 + 主角反常行为 + 致命威胁，或 主角被压制到极限 + 金手指激活。

**结尾**：短篇爆款的情感闭环：结局 1 章完成大爽点回收（身份曝光/谜底揭开/反杀成功）并落到情感满足，不留未解之谜。可虐可悲，但必须以主角的"赢"或"释然"收束，让读者合上文件时觉得"这口气出了"。

**对话**：符合角色身份和世界观设定，传递信息的同时塑造人物。**网文化要求**：短句、对抗性强、信息量大（一问一答之间推进剧情）；对话是打脸和钩子的主要载体，重要台词要有记忆点（金句）。同时，语言必须带有**类型调性**：
- **赛博朋克**：带黑话与数据指标，对话像在报数据（"你的信用点只够买半条命"）
- **硬科幻**：技术克制感，用精确数字替代形容词（"误差0.003秒，不是巧合"）
- **心智奇观**：哲学留白，问答之间留沉默（"你确定你是你吗？……我不确定。你呢？"）
- **宇宙恐怖**：不可名状的省略，用感官细节替代解释（"它……在数我的肋骨。"）

**标点**：**减少破折号"——"的使用**。优先用句号、逗号、冒号、引号组织语句。若需强调或转折，改用其他句式（换行、分句、冒号说明、短句并列）。全文"——"出现次数应控制在个位数以内。
**引号**：所有对话与引用一律用「」表示；对话内再次引用用『』。全文不得出现 " " " " 形式的引号。

```
「盘古系统说你的情感模型有17%的异常偏移。」周牧没有抬头，盯着全息面板上的数据流。
陈燃笑了：「那83%呢？」
「足够让安全部认为你还有救。」
「不够让你这么认为，对吧？」
周牧关掉了面板。审讯室的灯暗了一度。「问题在于，陈燃：那17%到底是人性，还是它的。」
「你有办法区分吗？」
「没有。所以你还坐在这里。」
```

### 7. 质量检查

**改编纯度（原有检查）**：
- [ ] 读者能否从故事中推断出原始故事是什么？——如果能，需要改得更彻底
- [ ] 人物是否与原文有可类比的特征？——如果有，继续替换
- [ ] 开场场景是否让人联想到原文开场？——如果是，换一个完全不同的切入点
- [ ] 中国元素是否深度融入世界观（而非生硬贴标签）？
- [ ] **时代一致性**：是否混入古代生活场景/器物/职业/文言（老槐树、石桌、油灯、布衣、教书先生念古文、纳鞋底、铁匠铺等）？有则替换为科幻时代对应物（数据庭院、全息光屏、智能织物）
- [ ] **未来转译**：中国哲学/神话/典故是否只以命名、算法代号、制度逻辑等未来形态出现，而非古代原貌直接搬用？
- [ ] 任意描写段落去掉时代词后是否依然读得出科幻感？（换掉时代词就变成古代戏 = 时代割裂，需重写）
- [ ] 科幻设定是否驱动了情节？（而非仅作为背景装饰）
- [ ] 世界观的内部逻辑是否自洽？
- [ ] 故事是否有完整的情感弧线？
- [ ] 全文破折号"——"使用是否控制在个位数以内？
- [ ] 全文引号是否统一为「」和『』，未出现 " " 或 " "？

**爆款度（网文标准检查）**：
- [ ] 第1句是否即冲突（无世界观铺垫）？
- [ ] 主角是否在前500字内登场？
- [ ] 金手指是否在前1000字内戏剧性亮相？
- [ ] 前三章是否含完整打脸流程（铺垫→爆发→震惊）？
- [ ] 每章是否以钩子结尾？（悬念/反转/期待/危机）
- [ ] 每章是否有至少1个小爽点？每3-5章是否有中爽点？
- [ ] 主角人设是否有极致反差？
- [ ] 是否设计了「第一个打脸对象」和「背后压迫势力」？
- [ ] 结尾是否情感闭环 + 大爽点回收，不留连载坑？
- [ ] 是否附上爆款配套（书名/简介/卖点/投放）？

**终极检验**：将新故事给一个熟悉原文的人看，ta 应该无法将其与原故事联系起来；同时给一个番茄读者看，ta 应该愿意一章章读下去。

## 示例转化

**原始故事**：简·奥斯汀《傲慢与偏见》——乡绅家庭的二女儿伊丽莎白与富有但傲慢的达西先生之间因偏见和误解而历经波折最终相爱的故事。

**❌ 不合格的转化（保留了太多痕迹）：**
一个"傲慢"的星际舰队指挥官与"偏见的"殖民地情报官在星际外交中互生好感。→ *依然能看出是傲慢与偏见*

**✅ 彻底的转化：**

**新故事设定**：天宫联邦安全部 319 号审讯室，一名被捕获的外星共生体（前人类"陈燃"）接受意识审查。审查官周牧通过「盘古」记忆回放系统追溯陈燃为何在火星战役中背叛人类、与外星生命融合。

- **中国背景**：天宫联邦、盘古系统、火星战役、冉遗-7通讯阵列——完全是中国人的太空未来
- **人物完全替换**：不是恋爱中的男女，而是身份背叛者与制度审查者的对抗
- **情节驱动改变**：从"社交博弈"变成"审讯与抵抗"，每一章揭露一层融合真相
- **情感内核保留但载体更换**：原文的"放下偏见"→ 转化为"放下对'纯粹人类'身份的执念"
- **叙事视角改变**：单视角——审查官周牧的第三人称限知视角，全程贴主角（篇幅短不再用双视角，避免代入感稀释）
- **不可回溯**：没有任何"傲慢的男人和偏见的女人"的痕迹

### 网文化黄金三章示范（同一新设定的爆款化开头）

**第1章（前300字）**：周牧被当众撕毁资格证那一刻，他脑内响起一道从不存在于联邦数据库的声音：「系统绑定完成。检查到宿主正在被淘汰，是否启动盘古底层权限？」

**第2章**：他利用权限黑入考核终端，完成不可能通过的极限测试，惊呆全场；背后有人使坏调他进"永夜"监狱船。（小打脸）

**第3章**：监狱船航行中，系统提示「检测到舷外信号源：正是 30 年前『广寒宫事件』的残响」。他确认这不是巧合。（大打脸/身份暗示 + 钩子）

> 转化要点：把审查官的"制度对人性"议题，加工成"被压制的维修师 + 反杀 + 追查惊天真相"的爽文骨架，情感内核仍在但被爽感全程托举。

## 注意事项
- **宁可改得过火，不要改得不够**——"完全看不出"是硬性要求
- 不要害怕颠覆原作的类型和基调：原作的喜剧 → 可以改为悲壮的史诗
- 科幻设定要有起码的自洽性，不要为了求变而出现逻辑漏洞
- 情感是核心——新技术设定下的新人物仍然需要让读者共情
- 中国元素要自然融入，避免"生硬标签化"——不是堆砌"龙""红色""长城"就叫中国风
- **全文只允许一个时代**：科幻时代的日常必须是未来的（光屏、全息、智能织物），哲学/神话/典故只做未来转译（命名、代号、算法逻辑），严禁古代生活场景、器物、职业、文言混入；意识体/数字生命的栖居形态同样要未来化，不能住老槐树小院、不能用毛笔写信
- 输出固定在 10000~15000 字，与原文篇幅无关，以新故事完整性为准
- 全文减少"——"破折号的使用，控制在个位数以内
- 全文引号必须为「」/『』，绝不输出 " " 或 " "
- 如果用户有偏好的科幻子类型，优先满足；否则选择最远离原文气质的类型
- **锚定番茄短篇爆款**：快节奏、强冲突、3秒定生死；世界观让位给剧情
- **爆款配套是硬性交付物**（书名/简介/卖点/投放），不是可选项；这是流量第一道闸门
- **结构与爽点优先于文笔**：读者追的是"接下来会怎样"，不是"这段写得美不美"
