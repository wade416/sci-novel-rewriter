# 赛博朋克写作参考

## 核心美学
赛博朋克是"高科技，低生活"（High Tech, Low Life）的结合。

### 视觉元素
- **霓虹灯**：红、蓝、紫色为主，映照在雨水中
- **全息投影**：巨大的广告、虚拟偶像、数据流
- **狭窄空间**：香港式密集建筑、小巷、天台
- **雨水**：永恒的雨，象征压抑和净化
- **城市**：密集的建筑、小巷、天台
- **交通**：高速、地铁、公交
- **生态环境**：城市中的绿色空间、公园、街道
- **义体**：机械手臂、电子眼、神经植入物

### 听觉元素
- 电子音乐、合成器音效
- 机械运转声、数据流动的声音
- 雨声、霓虹灯的嗡鸣

### 嗅觉元素
- 机油味、臭氧味
- 街边小吃的香气（中国元素）
- 穷人区的污水和垃圾的臭味
- 富人区的整洁和花朵的香气

## 中国赛博朋克特色

### 地名设定
- **梦想市**：金融中心，城市变成了全息投影展示区，仿生人生活在这里，与人类共处。
- **天网城**：科技中心，著名科技公司的巨型总部，机器人在这里工作。
- **基因塔**：基因技术中心，从事各种基因工程项目的科技大厦，克隆人在这里出生。
- **霓虹巷**：地下黑市，美食与义体交易并存，底层人在这里工作。
- **天穹城**：贫富分化最严重，上层浮空区与地下污水区，富人在这里工作，底层人在这里生活。

### 中国特色科技
- **户籍芯片**：每个人出生就植入，记录身份、信用、健康
- **信用点系统**：社会信用分数决定你能去哪里、做什么
- **国企垄断**：大型国企掌控核心科技，私人企业只能做边缘业务
- **天网监控**：无处不在的摄像头和AI监控
- **虚拟现实**：底层人的娱乐方式，他们可以在虚拟世界中进行游戏、社交、学习等，逃避现实世界的问题。
- **克隆人伴侣**：与克隆人可以建立短时间的伴侣关系，他们可以在现实世界中进行互动，分享情感。

### 文化元素
- **道家哲学**：AI觉醒时，会思考"道"的问题
- **儒家伦理**：仿生人是否有"仁"？
- **神话代号**：AI系统叫"龙"、"凤"、"麒麟"
- **节日**：节假日时，仿生人也会放假，但只能待在充电站。

## 人物设定模板

### 主角类型
1. **觉醒者**：发现自己是仿生人/克隆人，开始寻找真相
2. **黑客**：在虚拟世界和现实世界之间穿梭
3. **义体医生**：为底层人做非法义体改造
4. **企业叛逃者**：从大公司逃离，带来机密信息
5. **记忆猎人**：专门找回被删除或篡改的记忆

### 反派类型
1. **企业高管**：为了利益不惜牺牲一切
2. **AI执法者**：严格执行程序，没有感情
3. **义体猎人**：追捕逃亡的仿生人/克隆人
4. **记忆篡改师**：可以修改人的记忆，包括身份、记忆、情感等。

## 情节模式

### 觉醒之旅
1. 主角过着普通生活
2. 发现异常（记忆不符、身体异常）
3. 追查真相
4. 发现自己是仿生人/克隆人
5. 身份危机
6. 接受或拒绝自己的身份
7. 做出选择，改变世界或改变自己

### 反抗之路
1. 主角生活在底层
2. 发现上层的秘密
3. 组织反抗
4. 与企业/AI对抗
5. 牺牲与胜利
6. 新的秩序建立（或失败）

## 写作技巧

### 开头技巧
- 开头暴击，直接进入故事核心，避免介绍背景。
- 用一个具体的赛博朋克场景开始，展示世界的基本设定。
- 引入主角的特殊之处，如身份、能力、情感等。
- 用细节建立世界观，展示世界的基本设定。

```
错误示范：这是一个赛博朋克的世界，科技很发达...
正确示范：林启明的义眼在雨中自动调焦，捕捉到那个熟悉的身影。
```

### 对话技巧
- 简洁有力
- 体现角色性格
- 可以有科技感，但不要过度

```
错误示范："我是一个仿生人，我的程序告诉我应该这样做。"
正确示范："你知道吗？我连眼泪都是程序写的。"
```

### 描写技巧
- 多感官描写（视觉、听觉、嗅觉）
- 用细节建立世界观
- 避免大段技术解释

```
错误示范：他的义体手臂是由钛合金制成的，里面有128个微型马达...
正确示范：他的义体手臂在雨中泛着冷光，手指关节处有细微的电流声。
```

## 常见错误

1. **技术堆砌**：为了科幻而科幻，忽略故事本身
2. **翻译腔**：句子太长，不符合中文习惯
3. **世界观混乱**：设定不自洽，前后矛盾
4. **人物扁平**：只关注科技，忽略人物塑造
5. **结局仓促**：没有情感闭环

## 好的故事核

1. **身份认同**：我是谁？我从哪里来？
2. **自由意志**：我的选择是自由的吗？
3. **人性边界**：什么是人？仿生人算人吗？
4. **记忆与真实**：记忆被篡改后，我还是我吗？
5. **爱与程序**：AI能产生真正的爱吗？
